1. Studio Dashboard & Quick Overview

How to Switch Gear & Modes Live:

  1. Target Headphone / IEM: Defaults to your KZ ZAR (1DD + 7BA). Pick any headset or IEM from your personal collection in the categorized dropdown.
  2. Sound Target Curve: Choose between Warzone / CoD Footsteps Priority, Treble Tamer, Competitive Spatial, or Harman Reference.
  3. Sound Mode: Select Surround (Full Spatial), Cinema (5.1), or Pure Stereo.

  5. Click the red APPLY button. Equalizer APO reloads your changes immediately while your game is running.

2. Hi-Fi Cable Setup & Elgato Wave Link 3.0 Routing

Windows Sound Panel (mmsys.cpl)

Click the Open Sounds button inside Triple R Audio to open the Windows Sound Control Panel directly:

  • Your virtual audio pipe appears as Hi-Fi Cable Input (VB-Audio Hi-Fi Cable) (or named Art Tune as shown in your screenshot).
  • Click Configure (bottom-left) and select 7.1 Surround so games output all 8 discrete directional channels.
  • Click Properties -> Advanced and set the format to 24-bit, 48000 Hz (Studio Quality).

Using Elgato Wave Link 3.0 (Tune ON/OFF & Normal Audio)

With your Elgato Wave:XLR and Wave Link 3.0 virtual channels (Browser, Discord, Game), you have two seamless ways to switch between Tuned Game Audio and Normal Audio:

  1. In-App 1-Click Bypass: In Triple R Audio's footer or Studio tab, switch Tune Mode to Normal Audio (Bypass) and click APPLY. This keeps your routing intact while bypassing all aggressive EQ and compression.
  2. Wave Link 3.0 Channel Routing:
    • Add Hi-Fi Cable Output as an Input Channel in Wave Link 3.0.
    • Route Call of Duty / Warzone to Hi-Fi Cable Input in Windows Volume Mixer for full footstep tuning.
    • Keep Discord, Browser, and Music routed to their own Wave Link channels (Browser, Discord) so your friends' voices and Spotify music stay 100% natural and untouched by the game EQ!

3. Loudness Equalization (LEQ) & Release Time Slider

Windows Loudness Equalization raises quiet footsteps and compresses loud explosions. The secret to competitive gaming audio is the Release Time slider:

Figure 3: Enhancements Tab with Loudness Equalization Checked
Figure 4: Release Time Slider Set to Short (2) for Instant Footstep Recovery

Controlling LEQ Directly Inside Triple R Audio:

  • No Manual Digging Required: In Triple R Audio, use the built-in Loudness EQ Toggle and Release Time Slider (2 = Short/Instant to 7 = Long/Slow) directly inside the Studio tab!
  • Release Time 2 (Short - Recommended for CoD/Warzone): Causes the audio compressor to recover almost instantaneously after a gunshot or airstrike, so enemy footsteps are immediately audible again.
  • 1-Click Registry Unlock Script: If a new PC or audio device is missing the Enhancements tab, click Unlock & Install LEQ on Hi-Fi Cable in the Setup tab to automatically inject the Microsoft APO registry keys and restart Windows Audio.

4. Full Guide: How to Use Squiglink Auto-EQ

Squiglink is an open measurement database containing exact frequency response graphs for thousands of IEMs (including KZ, Tangzu, QKZ, Truthear, Simgot) and headsets.

Option A: Instant Background Auto-EQ (Inside Triple R Audio)

  1. Click the Squiglink Auto-EQ tab in Triple R Audio.
  2. Pick a measurement source (e.g., GadgetryTech for gaming headsets/IEMs or Crinacle) and select your desired Game Target (e.g., Call of Duty / Warzone Footstep Target or Black Ops 6 Target).
  3. Type your headphone or IEM model name and click Auto-EQ & Add Model. Triple R Audio automatically computes the biquad filters, saves the `.txt` file into your library, and selects it for you.

Option B: Using the Squiglink Website Manually

  1. In the Squiglink Auto-EQ tab, type your IEM name and click Open in Squiglink.
  2. On the Squiglink webpage, click the Equalizer tab on the left panel.
  3. Click Upload Target and select any target file from your library folder (or use the preloaded Warzone target).
  4. Click AutoEQ (set range from 20 Hz to 10000 Hz), then click Export Parametric EQ (for Equalizer APO).
  5. In Triple R Audio, click Import .txt EQ to load the downloaded file into your permanent collection.
